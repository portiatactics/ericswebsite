# ericswebsite

One-page artist landing page. Plain HTML + CSS, no build step.

- `index.html` — the page
- `styles.css` — styles
- `media/` — the "crow" video and poster image

Preview locally: open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.
